# 开源旅行手册 Skill

这是一套让 AI Agent 根据旅行需求生成完整网页旅行手册的基础版 Skill。它会整理每日路线、景点、购物、当地体验、餐饮、准备事项、语言锦囊和旅行贴士，并输出适合手机和电脑查看的 HTML 页面。

> 把“帮我做攻略”变成一份真正能在旅途中打开使用的手册，而不只是一段聊天答案。

## 能做什么

- 读取问卷或自然语言旅行需求
- 研究真实目的地、景点和餐厅
- 按区域和节奏安排每日路线
- 生成带地图、小红书地点搜索、清单和主题切换的网页
- 使用 Trip Mode 查看当天安排，并通过“调整行程”增删、编辑或排序地点
- 在有可靠资料时展示开放时间、预约要求和 Google Maps 评分
- 为每天生成 Mini Route 和离线手绘路线概览
- 保留实用的拍摄建议、时间边界和超时备选
- 通过结构、图片、内容和浏览器审计后才允许交付

## 使用说明

如果已经确定交通和住宿，可以直接上传订单截图，或告诉 Agent 航班号、酒店名称和日期，它会把这些事实整理进手册。尚未确定也不影响行程生成，相关位置会先留空并显示“待确认”。

“调整行程”会生成可复制的文字申请，方便继续交给 Agent 更新手册。

## 使用方法

打开 `assets/intake-questionnaire/index.html`，用 1–3 分钟填写核心问题，点击“整理手册需求”，复制生成的文字并发送给支持 Skill 的 Agent。也可以直接说：

> 使用 $build-personalized-travel-guide-open-source，为我制作一份 11 月两个人去清迈 5 天的旅行手册。节奏轻松，喜欢美食、寺庙和拍照。

在 Codex 中，将整个文件夹放进个人 Skills 目录后即可调用。Claude Code、WorkBuddy 或其他支持本地 Skill/Prompt 的 Agent 可以读取 `SKILL.md` 并按其中命令运行；具体安装入口因产品而异。

### 快速安装

1. 下载或 Clone 本仓库。
2. 将整个 `build-personalized-travel-guide-open-source` 文件夹放入 Agent 的 Skills 目录，不要只复制 `SKILL.md`。
3. 重新打开任务后，说“使用 `$build-personalized-travel-guide-open-source` 帮我制作旅行攻略”。
4. 填写自带问卷，或直接回复按主流默认方案生成。

Skill 使用 Python 3.10 或更高版本。图片验证需要 Pillow；建议直接使用 Agent 环境中已包含 Pillow 的 Python。

## 输出内容

最终工作目录中的 `index.html` 是可直接用浏览器打开的旅行手册。同目录还会包含本地图片、研究数据、来源记录和验证结果。

## 仓库结构

```text
SKILL.md                    Agent 入口和核心规则
assets/                     问卷、数据契约与页面母版
references/                 内容、图片、渲染和审计说明
scripts/                    研究、编译、渲染和验收脚本
LICENSE                     MIT License
THIRD_PARTY_NOTICES.md      第三方组件和素材说明
```

页面母版保留一份已公开的巴厘岛编辑示例，用于锁定版式和交互水平。其中交通与住宿均为中性待确认占位，不包含真实订单信息。生成新目的地时，所有目的地内容都会由验证后的数据重新渲染。

## 联网、评分和动态信息

联网能力因 Agent 和运行环境而异。部分实时开放时间、票价、图片或 Google 数据可能缺失。Google 可访问时，Agent 会为相关景点和餐厅逐一查询评分与评论数；评论数缺失时仍可展示已核实的评分。单个地点打不开时会换简短精确入口重试一次；只有连续两个不同地点都无法打开，才停止剩余评分检索。任一地点成功打开都会重置连续失败计数，已取得的评分不会丢失，评分失败也不会阻止网页生成。

动态信息会变化。出发前请通过景点、交通或活动官方页面再次确认开放时间、票价、预约方式和临时关闭情况。

## 常见问题

- **运行环境不通过**：使用 Python 3.10 或更高版本，并选择已经包含 Pillow（PIL）的 Python 环境；不必重开任务或重复研究。
- **图片下载失败**：换用同一地点的官方或开放许可图片；不要用无关图片冒充。
- **Google 评分没有显示**：先确认运行环境能否打开 Google。连续两个地点都无法访问时，Agent 会省略本轮评分；能访问时会继续逐个查询相关景点和餐厅。
- **普通旅行搜索出现 500 或敏感内容提示**：不要原样反复重试。将查询缩短为英文或罗马字店名加城市，最多恢复尝试一次；仍失败时保留已完成文件，等平台恢复后从当前研究包继续。
- **交通或住宿待确认**：提供已预订事实，或保持待确认继续生成。
- **页面未完成**：查看 `.travel-build-state.json` 中的 `next_required_action`。
- **动态信息不确定**：采用保守描述，并注明出发前复核。

问卷内容只保存在当前浏览器的本地存储中，不会上传服务器。使用公共设备后请点击问卷中的“清除已保存内容”。
